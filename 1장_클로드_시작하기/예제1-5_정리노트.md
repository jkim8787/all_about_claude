# 데이터분석실무사 공부 정리 노트

## 1과목: 데이터 이해

- 정형 데이터: 표 형태로 정리 가능한 데이터 (엑셀, DB 테이블 등)
- 비정형 데이터: 텍스트, 이미지, 영상처럼 정해진 구조가 없는 데이터
- 반정형 데이터: JSON, XML처럼 어느 정도 구조는 있지만 고정된 스키마는 없는 데이터
- 데이터베이스 기본 용어: 테이블, 행(row), 열(column), 기본키(Primary Key), 외래키(Foreign Key)

## 2과목: 데이터 수집과 정제

- 결측치 처리 방법
  - 삭제: 결측치가 있는 행/열을 아예 제거
  - 대체: 평균값, 중앙값, 최빈값 등으로 채워 넣기
  - 예측: 다른 변수로 결측치를 예측해서 채우기
- 이상치 탐지: 박스플롯(사분위수 기준), Z-score 방법이 자주 출제됨
- 데이터 정제 절차: 수집 → 탐색 → 결측치/이상치 처리 → 변환 → 검증

## 3과목: 데이터 분석 기초

- 기술통계: 평균, 중앙값, 표준편차, 분산의 개념과 차이
- 상관분석: 상관계수는 -1~1 사이 값, 0에 가까울수록 관계가 약함
- 회귀분석: 독립변수와 종속변수의 관계를 수식으로 표현
- 시각화 원칙: 목적에 맞는 차트 선택 (비교=막대그래프, 추세=선그래프, 비중=원그래프)

## 4과목: 엑셀/SQL 실무

- 피벗테이블: 데이터 요약·집계에 자주 사용, 실기에서 매년 출제
- VLOOKUP 함수 구조: =VLOOKUP(찾을값, 범위, 열 번호, 일치 옵션)
- SQL 기본 구문
  - SELECT 열 FROM 테이블 WHERE 조건
  - JOIN: 두 테이블을 연결할 때 사용 (INNER JOIN이 가장 기본)
  - GROUP BY: 특정 열 기준으로 데이터를 묶어서 집계

## 헷갈리는 부분 (다시 볼 것)
- 상관관계와 인과관계의 차이
- INNER JOIN과 LEFT JOIN의 결과 차이
- 표준편차와 분산의 계산 공식 차이
